# Acceptance Criteria

## Authentication
Register/login/logout work; invalid login is rejected; session behavior is preserved.

## Navigation / UX
Clean pre-auth experience; authenticated persistent sidebar; genuine expand/collapse; active route remains clear; Home, Create Content, History, Support, Settings work.

## Create Content
Product name/description accepted; multiple reference images supported; creative instruction accepted; UGC, Unboxing and Reviewer supported.

## Product Intelligence
Uses supplied/observable information; unsupported claims are not fabricated; Product Name and Product Description remain semantically distinct.

## Affiliate Package
All five canonical fields exist after generation; description is meaningful; caption is product/context aware; CTA is contextual; hashtags are relevant and safely normalized where appropriate; package follows selected language.

## Video
Primary outcome is a real playable AI video artifact. Product reference, content type, creative direction and scene/story intent influence generation where supported. Static/mock output is never represented as live. If no usable live capability exists, fallback status is honest.

## History
Projects persist; completed results reopen without regeneration; refresh and logout/login do not regenerate; affiliate package and stored video/result restore; download/copy/share remain available where supported.

## Quality Gate
UI presence alone is insufficient. Critical behavior must be tested against these observable criteria.
